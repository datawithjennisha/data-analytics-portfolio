# 📌 Project Explanation

| Category | Details |
|---|---|
| **Project Type** | End-to-End Sales Analytics Solution |
| **Platform Used** | Microsoft Excel |
| **Tools Implemented** | Power Query, Data Model, DAX, Power Pivot, Pivot Tables, Interactive Dashboard |
| **Primary Objective** | Transform raw transactional sales data into meaningful business insights |
| **Business Focus** | Revenue Analysis, Profitability Tracking, Product Performance, Seasonal Trends |
| **Data Processing** | Cleaned and transformed raw data using Power Query ETL workflows |
| **Data Modelling** | Designed Star Schema architecture with Fact and Dimension tables |
| **KPI Development** | Created DAX measures for Revenue, Profit, Margin %, Transactions, and Time Intelligence |
| **Reporting Method** | Developed Pivot-based analytical reports and interactive dashboards |
| **Dashboard Features** | KPI Cards, Pivot Charts, Slicers, Dynamic Filtering, Trend Visualizations |
| **Analytical Outcome** | Identified revenue concentration, seasonal patterns, product profitability, and inventory opportunities |
| **Business Impact** | Supported performance monitoring and data-driven business decision-making |
| **Skills Demonstrated** | ETL, Data Modelling, DAX, Dashboard Design, Business Intelligence Reporting |
